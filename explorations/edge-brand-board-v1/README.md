# Capptus Edge — Brand Board v1

12 October 2026. A portrait brand-expression board inspired by the user's supplied reference structure, using the existing Capptus Edge Raw Bloom direction.

## Deliverables

- Capptus-Edge-Brand-Board-v1.png — 2400 × 4660 presentation image.
- Capptus-Edge-Brand-Board-v1.pdf — one-page PDF with embedded font subsets and native typography.
- Capptus-Edge-Brand-Board-v1.svg — editable vector shapes, outlined type and embedded imagery; no font substitution.
- Authoring scripts remain in the local output workspace; this package contains portable review exports.

The board follows the supplied reference's hierarchy: brand opening, color proportions, graphic vocabulary, signage, mobile/stationery, apparel and posters. It uses Capptus imagery and graphics throughout; no reference-brand logo, tagline or symbols were imported.

The original Capptus PNG is embedded unchanged and proportionally placed throughout. EDGE is a separate editorial descriptor, not a replacement wordmark or approved new lockup. Montserrat uses the existing font files, and Impact retains the prior local Edge display study. Supporting colors, waveform language and applications remain proposals.

## Image-generation provenance

Two blank mockup photographs were generated with the built-in image tool: a front-facing limestone-wall billboard and an ivory hoodie. Exact prompts are in prompts.json and original images are in assets/. Existing Baja collages and creative portraits are reused from the project. Text, logo and waveform overlays were authored natively, ensuring exact artwork and editable placement. The logo on the hoodie is a flat concept placement, not a production embroidery proof. All photography is concept imagery; people are fictional.

## Validation

Final PDF rendered and visually inspected. No clipped copy or unintended overlaps observed. Original-logo hashes and proportions, PDF page size, required copy, PNG dimensions, and exact palette fields were checked. Static application mockups do not demonstrate functioning interfaces. These checks describe the original board export; repository packaging is checked separately.
