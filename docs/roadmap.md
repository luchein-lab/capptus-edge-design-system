# Roadmap

## Current baseline

Mineral Bloom is the company-wide repository direction selected on 23 October 2026. The original logo, supplied copy, Bricolage Grotesque and Manrope are retained. The palette, token source and visual reference are published together.

## Further development

- Apply the system to representative proposals and business documents with actual approved content.
- Develop product-specific components, states and accessible semantic colours from real requirements.
- Establish print conversions and material proofs before physical production.
- Test audience associations and recognition; do not infer them from studio precedents.
- Resolve any future practice descriptors or separate lockups without altering the original logo by default.

## Maintenance

Edit the token JSON, regenerate the CSS, and run the project check. Review responsive layouts and interactions after relevant changes. Update validation records at the level actually tested. Keep historical assets in the archive and commit or publish subsequent changes only with authorization.
