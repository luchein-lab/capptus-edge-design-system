# Roadmap

## 0. Foundation — completed

- Preserve and inventory the two supplied sources.
- Document evidence, existing copy, constraints and unresolved choices.
- Establish project instructions and the initial specification.
- Add a local integrity/documentation check and Git ignore rules.

## 1. Resolve the creative direction

- Current review: [three routes and recommendation](creative-direction.md), 9 October 2026. Raw Bloom is the preferred route; production details remain open.
- Original corporate logo verified and packaged; confirm the Edge lockup and tagline hierarchy.
- Develop a small set of Edge compositions grounded in both references.
- Resolve blue/yellow versus earth/citron roles, typography and art direction.
- Record the selected direction without changing the logo or inventing new brand copy.

## 2. Build the system

- Define approved color, type, spacing, layout, border and motion tokens.
- Document logo use, photography, digital illustration and icons.
- Select a lean implementation stack for the agreed showcase.
- Build reusable components and representative agency applications.

## 3. Validate

- Check visual consistency at representative viewport sizes.
- Verify text contrast, semantics, focus, keyboard interaction and reduced motion as applicable.
- Check source/token/component agreement and asset provenance.
- Record automated checks separately from visual and user approval.

## 4. Prepare GitHub

- Resolve repository owner and visibility; suggested name: `capptus-edge-design-system`.
- Review exactly which references, brand assets, client marks, claims, and fonts belong in the chosen destination. The current .gitignore excludes original references and local renders by default.
- Choose appropriate licensing/ownership notices; do not assume open-source rights for brand material.
- Add build instructions and CI when implementation exists.
- Initialize Git and create the repository when requested. Commit and push only with explicit user authorization.
- Verify the resulting remote, branch, visibility, and published content.
