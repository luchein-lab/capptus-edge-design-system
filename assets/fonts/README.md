# Font provenance

The visual reference uses the existing, unmodified local Google Fonts WOFF2 files selected for Capptus work:

- Bricolage Grotesque, Latin variable font, weights 200 to 800. Copyright 2022 The Bricolage Grotesque Project Authors. See [license](bricolage-grotesque-OFL.txt).
- Manrope, Latin variable font, weights 200 to 800. Copyright 2018 The Manrope Project Authors. See [license](manrope-OFL.txt).

The original stylesheet with source URLs is retained in [google-fonts-source.txt](google-fonts-source.txt). Font hashes appear in the parent asset manifest. The files support the Spanish text shown in this reference; other scripts may need additional licensed subsets.
